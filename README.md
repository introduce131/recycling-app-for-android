# ♻️ ECOBIN

- ECOBIN은 환경 보호를 위한 올바른 재활용 방법을 안내합니다.<br>
- 자원을 올바르게 분리배출 하는 방법을 제공하고, 현재 내 위치 근처의 탄소중립포인트 사용처 정보를 제공하고<br>
- 실시간으로 걸음 수에 비례한 탄소저감량을 표시함으로써 재활용 활동을 더욱 편리하고 효과적으로 만들고자 하는 목적을 가진 애플리케이션입니다.
